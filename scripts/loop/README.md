# scripts/loop — the improvement loop's committed tooling

The loop's protocol is `.claude/skills/improveloop/SKILL.md`; the passes are `docs/reference/loop-passes.md`;
the pattern catalog is `docs/reference/loop-patterns.md`. This folder holds what a session used to rebuild in
its scratchpad every time.

| File | Role |
|---|---|
| `drift.mjs` | The outside-loop drift line (session-start step 4; `--vs` diffs against the last close-out's line). |
| `coverage.mjs` | Surface × pass "last audited" matrix from the ledger, the archive and the findings headings (one surface per row or heading, plus any joined to it with a literal ` + ` before the row's first colon, outside parentheses); `--check` rejects a rotation note that contradicts the record. |
| `closeout.mjs` | The mechanical close-out: compaction, the ledger checks, i18n, inline JS, llms/sitemap `--check`, coverage, every detector, every static check that exists. `--static` never writes. |
| `detect-<id>.mjs` | One detector per catalog pattern. So far: `detect-latin-sentence-boundary-in-hebrew-prose.mjs` (static, the CSV's `he` column); `detect-author-display-defeats-the-hidden-attribute.mjs` (rendered: its own static server and Chromium over every root page at 1280 and 800, ~70 s; skips itself when Playwright is absent). Contract: reads the shared harness, `--plant` injects one known hit into a scratch copy and must report it, `--json` prints `{ id, hits: [{ file, line, note }], delta }`; a run whose plant fails is never a clean run. |
| `probes/S<N>-<slug>.mjs` | A fix's own probe, committed only when no smoke scenario or ACTIVE pattern covers it; `regress.mjs --last 2` runs them at session start (to come). So far: `S553-sw-precache-revalidates.mjs` — the worker's install after a `VERSION` bump through a warm HTTP cache (an in-process server with `max-age=600`, the real worker, `--control` serves the plain `cache.add(url)` and must report the stale precache).; `S564-dashboard-calendar-lines-follow-settings.mjs` — the holiday, Shabbat and Omer lines after a starter and a preset Load, two dates, the drawer's switches the control; `S564-dashboard-fullscreen-fits-the-screen.mjs` — Full Screen at 1024×768 / 1280×720 / 1920×1080 on two boards, the message on screen and the clock on one line; `S565-fontmaker-autosave-photos.mjs` — 8 phone photos picked on the wizard's default path, the autosave's work before its first yield, the snapshot = `JSON.stringify(project)`, Continue's photos (`ROOT=` runs a control copy); `S565-fontmaker-flatten-blur.mjs` — the lighting flatten's background estimate bit-identical to the shipped column walk on a 12 MP photo, full size and at 1800 px, and under 0.7× its time; `S565-dashboard-groups-of-n.mjs` — Make Groups by real clicks, six present / N cases, EN 1280 + HE 800; `S566-flash-unreached-not-missed.mjs` — Flash Cards' weakness tally after End Practice Early and a time limit, by real clicks; `S566-flash-results-grid.mjs` — after a 10-card drill, Practice Mistakes on screen at 1366×768 / 1280×720 and one column on a phone; `S570-torah-manifest-off-the-first-render.mjs` — the Total Torah manifest held 3 s, Sefaria stubbed from the MAM phrases: on PocketTorah the first verse comes before it with the picker's option enabled, a stored Total Torah source still waits for it; `S570-torah-staff-font-remeasure.mjs` — the Trope staff with its Hebrew TTF held 2.5 s (every remembered width fresh once settled) and an unused FontFace loaded afterwards (no re-render); `S571-generator-flip-hint-language.mjs` — Real Words Self-Check generated by real clicks in each UI, every vocab card's "tap to flip" in that language, and again after a switch and Generate; `S571-torah-side-by-side-hebrew-head-lang.mjs` — Side by side's Hebrew column head under `lang="he"` in both UIs, Sefaria stubbed from the MAM phrases.; `S572-generator-realwords-narrow-cards.mjs` — Real Words Reading and Self-Check by real taps on four phones and 800 / 1280 windows: every card whole and ≥ 100px on screen, the builder's columns at 1280 and on paper; `S572-install-hint-tours.mjs` — the iOS install hint forced on iPhone SE / 13, every tour page's whole tour by real taps on Next, nothing covered, the hint hidden while it runs and back after; `S572-nametags-typed-translit-aligns.mjs` — a typed transliteration's text starts where the automatic ones do in both UIs, its icon after the field.; `S573-flash-preset-keeps-device-fields.mjs` — a preset load or play keeps this device's audio, voice speed, hidden home button and two-sided printing; `S573-generator-gold-answers-and-flip-hint.mjs` and `S573-generator-selfcheck-score-contrast.mjs` — the screen-only gold text, the flip hint and Self-Check's score colours at AA in both themes; `S574-generator-header-tablet-row.mjs` — the header's buttons on their own row at tablet widths, 1px steps 1000 → 320; `S575-chrome-print-whole-blocks.mjs` — Resources, Contact, Privacy and Terms on Letter and A4: no card cut across sheets, no heading stranded at a sheet foot (poppler); `S576-dashboard-bulk-edit-builds-in-chunks.mjs` — Bulk preset edit over 200 presets at 4×: no task over 400 ms, a master switch, Copy to all and Cancel mid-build, every card in the accessibility tree; `S576-dashboard-schedule-edit-reaches-board.mjs` — a frozen Wednesday: Enable and a painted period reach the board at once, a board note survives an edit elsewhere and a language switch; `S576-flash-dictionary-wait.mjs` — a pasted All Dictionary code starts once the dictionary lands, and Start's "still loading" note clears when it lands or the deck changes; `S577-atlas-phone-stacked-and-swipe.mjs` — the Trope Atlas on three phones: Stacked as wide as the screen (EN/HE, stored), and a raw-touch swipe on the melody table past its end moving the page both ways (the intro text the control); `S577-dashboard-rename-keeps-the-board.mjs` — a frozen Wednesday: renaming the preset on now leaves a board note through the tick, its next run still applies. |
| `fixtures/` | Canned responses of the remote APIs the pages parse (E's shape-drift arm; to come). |

Every script here is plain Node, read-only unless its name says otherwise, and runs from any directory.
