Classes

A class holds its students: add a class, then add its students in the popup that opens. Edit class… reopens it. Students you never put in a class are under Students without a class.

Class view

Every student against every open assignment. Add puts a student on an assignment (they see it in their Torah Trainer at once); Assign a new reading… opens the Torah Trainer with that student already chosen.

Assignments

To make a new one, open the Torah Trainer, choose the parsha, aliyah or verse range as usual, and press Assign this reading. Students enter the code word in the Trainer to see the portion and record it.

Recordings

Edit assignment

Each student signs in to the Torah Trainer with a username and a password you give them — no email address. Print the login cards right after you create a batch; the passwords are shown only then. You can reset a password at any time.

Add students

Type one name per line (a first name or a nickname is enough — it is what the student sees), or take the names from a class list saved on this device. Then check the usernames and passwords in the preview and press Create.
